# 多文本快速复制工具

一键复制多个文件内容，快速复制到粘贴板。(一个个复制代码给AI太累了)

## 功能特点

- 📁 **选择文件夹** - 加载文件夹内的所有文件
- ✅ **批量勾选** - 支持文件夹批量勾选
- 📋 **一键复制** - 合并内容直接复制到剪贴板
- 🔍 **快速搜索** - 实时过滤查找文件
- 📝 **智能筛选** - 一键筛选代码文件或文本文件
- 🔄 **顺序调整** - 自由调整文件合并顺序

## 安装

```bash
pip install pyperclip
python 多文本快速复制工具.py
```

## 使用场景

- 向AI提问时批量发送代码文件
- 代码审查时收集多个文件
- 文档整理时合并文本内容

## 依赖

- Python 3.6+
- tkinter（Python自带）
- pyperclip
